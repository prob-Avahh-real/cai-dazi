# 训练自定义食材分类 CoreML 模型

## 概述

菜搭子的识别管线支持三级策略自动降级：
1. **CoreML 自定义食材模型**（最高精度）→ 需按本文档训练
2. **Vision 内置分类器**（通用物体识别）→ 开箱即用
3. **手动输入**（兜底）→ 无模型且 Vision 失配时自动触发

## 第一步：准备训练数据

### 目录结构

```
TrainingData/
├── 番茄/
│   ├── tomato_01.jpg
│   ├── tomato_02.jpg
│   ├── tomato_03.jpg
│   └── ...
├── 土豆/
│   ├── potato_01.jpg
│   └── ...
├── 鸡蛋/
│   └── ...
└── ... (每种食材一个文件夹)
```

### 数据要求
- 每种食材 **至少 30 张**照片（建议 50-100 张）
- JPG/PNG 格式
- 不同角度、光照、背景
- 覆盖：
  - 单个食材特写
  - 多个同类食材
  - 菜市场/超市环境
  - 不同成熟度/品种

## 第二步：用 CreateML 训练

### 1. 打开 CreateML
- Xcode → Open Developer Tool → CreateML
- 或从 Applications 文件夹直接打开

### 2. 新建项目
选择 **Image Classification** 模板

### 3. 导入数据
- 将 `TrainingData/` 整个文件夹拖入 CreateML
- CreateML 自动把子文件夹名当作类别标签
- 建议训练/验证比例：80/20（默认即可）

### 4. 配置训练参数

| 参数 | 推荐值 |
|---|---|
| Iterations | 25 |
| Augmentation | ✅ Crop, Rotate, Blur, Noise, Exposure |

### 5. 开始训练
点击 **Train** 按钮

### 6. 评估模型
训练完成后检查：
- **Precision**（精确率）> 85%
- **Recall**（召回率）> 85%
- 混淆矩阵：无明显类别混淆

## 第三步：导出和集成

### 1. 导出模型
- 在 CreateML 中点击 **Output** 标签
- 点击 **Get** → 保存为 `IngredientClassifier.mlmodel`

### 2. 拖入 Xcode 项目
- 将 `IngredientClassifier.mlmodel` 拖入 `菜搭子/Models/` 目录
- Xcode 会自动生成 Swift 接口类
- **无需额外代码**，RecognitionService 已在启动时自动加载

### 3. 验证加载
运行 App 后在 Xcode Console 应看到：
```
✅ 已加载自定义食材分类模型
```

若输出 `ℹ️ 未找到自定义食材模型`，检查 .mlmodel 是否已加入 target。

## 进阶：持续改进模型

### 添加新品种
1. 收集新食材的 50+ 张图片
2. 在 TrainingData 中新建文件夹
3. 重新训练

### 处理误识别
1. 收集被误识别的图片
2. 放入正确类别的文件夹
3. 重新训练

### 迭代流程
```
每月收集一次用户反馈 → 补充数据 → 重新训练 → 随 App 更新发布
```

---

## 快速开始（无模型时）

即使没有训练自定义模型，菜搭子也能工作：
- Vision 内置分类器覆盖约 50 种常见食材
- 低置信度时自动提示手动输入
- 手动输入的结果会加入扫描历史，持续丰富数据
